# Shared Storage API

A neutral file-exchange space for apps and AI agents running under `log.scrambler-lab.com`. One app writes a file; another reads it. No browser, no login — just a shared static token in every request header.

**Base URL:** `https://log.scrambler-lab.com/api/shared`

---

## Setup (one-time)

### 1. Generate the static token

The token is a JWT signed with the server's `JWT_SECRET`. Generate it once from the `backend/` directory:

```bash
cd backend
python -c "
from dotenv import load_dotenv; load_dotenv()
import os; from jose import jwt
token = jwt.encode(
    {'type': 'shared_storage', 'iss': 'scrambler-lab'},
    os.environ['JWT_SECRET'],
    algorithm='HS256'
)
print(token)
"
```

### 2. Add to `.env`

```
SHARED_STORAGE_TOKEN=<paste token here>
```

### 3. Restart the server

```bash
./start.sh   # or start_local.sh for dev
```

The token is static — it doesn't expire and never changes unless you regenerate it (which requires updating all apps that use it).

---

## CORS

Browser-based callers require their origin to be listed in `CORS_ORIGINS` in `backend/.env`. Server-side callers (scripts, AI agents) are not subject to CORS and need no changes.

**Currently allowed origins** (keep `.env.example` in sync when adding new ones):

| Origin | App |
|---|---|
| `http://localhost:5173` | Local Vite dev server |
| `http://localhost:3000` | Local dev (alt port) |
| `https://extensions.shopifycdn.com` | Shopify storefront extension |

To add a new origin: append it to `CORS_ORIGINS` in `backend/.env` (comma-separated) and restart the server. No code change needed. The server logs the `Origin` of every `/api/shared/` request at `INFO` level (`cors_debug` logger), so you can identify new callers before adding them.

---

## Authentication

Every request must include the token in the `Authorization` header:

```
Authorization: Bearer <SHARED_STORAGE_TOKEN>
```

Requests without a valid token receive `401 Unauthorized`.

## Endpoints

### PUT `/api/shared/{filename}` — Write a file

Writes raw content to the named file. Creates the file if it doesn't exist; replaces it if it does.

**Request:**
- `Authorization: Bearer <token>` (required)
- `Content-Type: <content-type>` (required, see supported types below)
- Body: raw file content (bytes)

**Response `200 OK`:**
```json
{
  "filename": "result.json",
  "content_type": "application/json",
  "size": 87,
  "created_at": "2026-06-10T12:00:00+00:00",
  "updated_at": "2026-06-10T12:01:30+00:00"
}
```

**Errors:** `400` bad filename · `401` bad token · `413` file too large · `415` unsupported content type · `503` server busy

---

### GET `/api/shared/{filename}` — Read a file

Returns raw file content with its original `Content-Type`.

**Request:**
- `Authorization: Bearer <token>` (required)

**Response `200 OK`:** raw bytes with the stored `Content-Type` header.

**Errors:** `400` bad filename · `401` bad token · `404` file not found · `503` server busy

---

### DELETE `/api/shared/{filename}` — Delete a file

Removes the file and its metadata.

**Request:**
- `Authorization: Bearer <token>` (required)

**Response `204 No Content`**

**Errors:** `400` bad filename · `401` bad token · `404` file not found · `503` server busy

---

### GET `/api/shared/` — List files

Returns all stored files with their metadata. Note the **trailing slash**.

**Request:**
- `Authorization: Bearer <token>` (required)

**Response `200 OK`:**
```json
[
  {
    "filename": "note.txt",
    "content_type": "text/plain",
    "size": 18,
    "created_at": "2026-06-10T11:00:00+00:00",
    "updated_at": "2026-06-10T11:00:00+00:00"
  },
  {
    "filename": "result.json",
    "content_type": "application/json",
    "size": 87,
    "created_at": "2026-06-10T12:00:00+00:00",
    "updated_at": "2026-06-10T12:01:30+00:00"
  }
]
```

## curl Examples

Set your token and base URL once:

```bash
export TOKEN="<your-SHARED_STORAGE_TOKEN-value>"
export BASE="https://log.scrambler-lab.com"
```

### Write JSON
```bash
curl -X PUT "$BASE/api/shared/result.json" \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"status": "ok", "value": 42}'
```

### Write plain text
```bash
curl -X PUT "$BASE/api/shared/note.txt" \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: text/plain" \
  -d "Hello from app A"
```

### Write an image (binary)
```bash
curl -X PUT "$BASE/api/shared/photo.jpg" \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: image/jpeg" \
  --data-binary @/path/to/photo.jpg
```

### Write markdown
```bash
curl -X PUT "$BASE/api/shared/report.md" \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: text/markdown" \
  -d $'# Report\n\nGenerated by AI agent on 2026-06-10.'
```

### Read a file
```bash
curl -H "Authorization: Bearer $TOKEN" \
  "$BASE/api/shared/result.json"
```

### Read a file and save to disk
```bash
curl -H "Authorization: Bearer $TOKEN" \
  "$BASE/api/shared/photo.jpg" \
  -o downloaded_photo.jpg
```

### List all files
```bash
curl -H "Authorization: Bearer $TOKEN" \
  "$BASE/api/shared/"
```

### Delete a file
```bash
curl -X DELETE \
  -H "Authorization: Bearer $TOKEN" \
  "$BASE/api/shared/result.json"
```

### Test auth error (missing token)
```bash
curl -i "$BASE/api/shared/"
# Expect: 401 Unauthorized
```

### Test size limit
```bash
dd if=/dev/urandom bs=67000 count=1 | curl -X PUT "$BASE/api/shared/big.bin" \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/octet-stream" \
  --data-binary @-
# Expect: 413 Request Entity Too Large
```

## Python Client

```python
import httpx

class SharedStorageClient:
    def __init__(self, token: str, base_url: str = "https://log.scrambler-lab.com"):
        self._headers = {"Authorization": f"Bearer {token}"}
        self._base = base_url.rstrip("/")

    def upload(self, filename: str, data: bytes | str, content_type: str) -> dict:
        """Write a file. Raises httpx.HTTPStatusError on failure."""
        if isinstance(data, str):
            data = data.encode()
        r = httpx.put(
            f"{self._base}/api/shared/{filename}",
            content=data,
            headers={**self._headers, "Content-Type": content_type},
        )
        r.raise_for_status()
        return r.json()

    def download(self, filename: str) -> tuple[bytes, str]:
        """Read a file. Returns (content_bytes, content_type)."""
        r = httpx.get(
            f"{self._base}/api/shared/{filename}",
            headers=self._headers,
        )
        r.raise_for_status()
        return r.content, r.headers.get("content-type", "")

    def delete(self, filename: str) -> None:
        """Delete a file."""
        r = httpx.delete(
            f"{self._base}/api/shared/{filename}",
            headers=self._headers,
        )
        r.raise_for_status()

    def list(self) -> list[dict]:
        """List all stored files with metadata."""
        r = httpx.get(f"{self._base}/api/shared/", headers=self._headers)
        r.raise_for_status()
        return r.json()


# Example usage
import os
client = SharedStorageClient(token=os.environ["SHARED_STORAGE_TOKEN"])

# Write JSON from app A
client.upload("result.json", '{"score": 0.95}', "application/json")

# Read in app B
data, ct = client.download("result.json")
import json
result = json.loads(data)
print(result["score"])  # 0.95

# List all files
for f in client.list():
    print(f["filename"], f["size"], "bytes")
```

## Filename Rules

| Rule | Detail |
|---|---|
| Allowed characters | `a-z A-Z 0-9 _ - .` |
| Max length | 255 characters |
| No path traversal | `..` is not allowed |
| No leading dot | `.hidden` is rejected |
| Extensions | Recommended but not required |

Examples of **valid** filenames: `result.json`, `photo_2026.jpg`, `report-v2.md`, `data123.txt`

Examples of **invalid** filenames: `../etc/passwd`, `.hidden`, `path/to/file.json`, `file name.txt`

---

## Supported Content Types

| Content-Type | Use for |
|---|---|
| `application/json` | JSON data |
| `text/plain` | Plain text, logs |
| `text/markdown` | Markdown documents |
| `image/jpeg` | JPEG images |
| `image/png` | PNG images |
| `image/gif` | GIF images |
| `image/webp` | WebP images |

Any other `Content-Type` returns `415 Unsupported Media Type`.

**File size limit:** 65 KB = 66,560 bytes. Larger payloads return `413 Request Entity Too Large`.

---

## Error Reference

| Status | Meaning | Common cause |
|---|---|---|
| `400` | Bad Request | Invalid filename (illegal characters, `..`, leading dot) |
| `401` | Unauthorized | Missing `Authorization` header, wrong token, or malformed JWT |
| `404` | Not Found | File does not exist |
| `413` | Request Entity Too Large | Body exceeds 66,560 bytes (65 KB) |
| `415` | Unsupported Media Type | `Content-Type` not in the allowed list |
| `500` | Internal Server Error | `JWT_SECRET` or `SHARED_STORAGE_TOKEN` not set in server `.env` |
| `503` | Service Unavailable | Lock timed out (write: 30 s, read: 10 s) — retry after a moment |

---

## Concurrency Behaviour

The server uses a **writer-preference read-write lock** per filename.

- **Simultaneous write + read on the same file:** the write runs first; the read waits until the write completes (up to 10 seconds), then proceeds.
- **Simultaneous write + write on the same file:** writes are serialized — one completes before the next begins.
- **Simultaneous reads (no write pending):** all reads proceed concurrently.
- **Different filenames:** operations on different files are fully independent and run concurrently.

If a lock cannot be acquired within the timeout, the server returns `503` and the client should retry.
